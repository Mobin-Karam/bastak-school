# Architecture documentation

Start with the [repository architecture](./repository-architecture.md), [system map](./system-map.md) and [dependency boundaries](./dependency-boundaries.md). The [workspace foundation](./workspace-foundation.md) defines the package DAG and install model; the [CMB reference and release policy](./cmb-reference-and-release.md) describes reusable backend packages. Check source before using an inventory as a current contract.

For feature implementation use [architecture and data integrity](../engineering/architecture-and-data.md). For deployment effects use the [CI/CD pipeline](../operations/ci-cd-pipeline.md).
