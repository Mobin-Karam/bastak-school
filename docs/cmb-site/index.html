ONE CONFIGURATION FILE

Start with a single CMB config.

npm install @moshaver/cmb-starter

// cmb.config.cjs
module.exports = {
  serviceName: "notes-api",
  modules: ["auth", "authorization", "notifications", "realtime"],
};

const { createCmbRuntime } = require("@moshaver/cmb-starter");
const cmb = createCmbRuntime(require("./cmb.config.cjs"));
await cmb.start();
await cmb.ready();

The starter resolves declared CMB dependencies. Your application still chooses its HTTP server, concrete storage adapters, secrets, routes, and domain rules.
