# Admin role-page visual captures

This folder contains 122 route-and-viewport captures, plus two attendance contact sheets:

- `principal/`, `teacher/`, `student/`, and `supervisor/` keep the role-specific route structure.
- Each role has `desktop/` (1440×900) and `mobile/` (390×844) views.
- `attendance-flow-desktop-contact-sheet.png` and `attendance-flow-mobile-contact-sheet.png` provide a quick comparison of the attendance workspaces.

The captures were made on 2026-10-28 using the local Admin UI with representative mocked responses. They are visual-reference artifacts only; they are not authenticated production screenshots or evidence of live backend data.
